# Evidence

本目录按 `../spec.md` 第 2.5 与 5.2 节归档。本轮只生成任务包并校验，业务实现与真实应用验收尚未执行。

- `package-validation/`：本轮结构、源码定位、状态板与生成视图记录；不表示修复已完成。
- 后续 Task 日志与用户路径证据使用 spec 指定位置；不得用空文件或旧失败复现充当通过证据。
- 每次执行记录日期、完整命令、工作目录、两仓 SHA、Node/浏览器版本、退出码、输入哈希和结果文件；凭据与真实用户文档不入证据。
- 实际场景截图、console、network 和 request/response 对应同一用例；预期注入失败与非预期错误区分。
- Phase 收尾记录完成任务、命令结果、场景通过数、未解决问题；仅证据齐全后更新状态。
