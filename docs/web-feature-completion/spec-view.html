人话摘要

- 给浏览器用户和外部 agent 补齐文档功能，操作从网页入口开始，在网页或服务端完成并得到真实文件。

- 覆盖现有五类文档的新建、打开、编辑和导出，并接入官方新增的 HTML 编辑器；HTML 接入必须在固定官方版本同步之后进行。

- 优先解决 Excel 公式、表格特征和图片读取不完整，再补 PDF 页面处理、Office 转换及演示文稿网页菜单功能。

- 打印、文字识别、模型和媒体功能允许依赖服务；开始操作前就要显示服务是否可用，不能执行到一半要求安装桌面版。

- 所有宣称可用的入口都必须通过成功、错误和恢复场景，导出文件还要重新打开核对内容。

- 不重写已有纯转换算法，不替代前置包的状态一致性、原子保存或工具契约修复；不把桌面安装器、自动更新和操作系统菜单列为网页文档功能。

用户流程（UF 步骤级脚本 → 流程图）

UF-001 五族网页入口闭环

前置: 隔离 Web profile、临时文档、各族构建就绪；对每族分别走新建、文件选择、拖入、最近文件、跨编辑器打开。

1
动作从上述真实入口新建或打开文件
界面显示加载、禁止尚未就绪的编辑
系统选择正确 app、加载字节并等待 ready
结果文件名与内容正确
2
动作修改一个可核对对象并保存
界面显示 dirty→saving→saved
系统用前置状态契约保存到许可目标
结果得到路径或下载文件
3
动作关闭后重新打开输出
界面显示加载后文档
系统重新解析磁盘字节
结果新内容存在，原有内容保留
取消或拒绝文件权限
取消选择器/拒绝写句柄
返回原页，保留 dirty
恢复: 重新选择或明确另存
损坏文件/缺失构建
解析失败或 app 资源缺失
显示具体文件/资源错误，编辑禁用
恢复: 修复输入/构建后重试

UF-002 Sheets 语义、图片与保存

前置: 自造可审计 XLSX fixture，覆盖共享公式主项/跟随项/绝对混合引用、名称、隐藏、筛选、保护、图像和透视；记录压缩包与预期单元格语义。

1
动作从首页打开 fixture 并读取范围/公式
界面加载完成后表格可交互
系统完整模型经 browser 或 sidecar 读取
结果公式、特征、媒体与 fixture 一致
2
动作改普通值、插入移动一张图片
界面单元格与图片即时更新、dirty 可见
系统复用 workbook 保存管线并保留特征
结果图像位置和文字值正确
3
动作保存并重开，读取同一范围与特征
界面saved 后重载
系统对照 OOXML 和 sidecar 语义
结果修改存在，共享公式/未触及特征仍在
sidecar 不可用/退出
启动缺二进制或操作中服务终止
开始前显示依赖或当前失败，保留会话
恢复: 恢复服务重新读取
非法图片/受保护目标
损坏图片、错误媒体关系或保护阻止写入
明确校验错误且原内容仍在
恢复: 改输入或按权限解锁后重试

UF-003 PDF 页面操作与 Office 转换

前置: 文本 PDF、扫描 PDF、多页尺寸 PDF、加密及损坏负例；输出到临时目录。

1
动作从 PDF 页面菜单选择提取/插页/尺寸/拆分/裁切
界面显示选择范围和待执行状态
系统复用 bytes 算法校验并执行
结果预览页数/范围/尺寸正确
2
动作选择 Word、Excel 或 PowerPoint 转换
界面显示进度和取消操作
系统worker 复用纯转换包；扫描页明确标记图像/OCR 模式
结果输出名称、格式、页数与警示准确
3
动作保存并从目标 app 打开
界面显示保存完成后打开目标
系统按真实字节解析输出
结果文本/图片与承诺模式一致
非法页码/损坏输入
空选页、越界、解析失败
就地指出错误，保留 PDF
恢复: 修正范围/重新选文件
worker 失败/取消
WASM 加载失败、资源耗尽、用户取消
显示已失败/已取消与可重试
恢复: 修复资源/缩小范围后重试

UF-004 Slides 共用事务与剩余文档功能

前置: 带布局、主题、分节、链接、媒体、母版、动画、演示配置的真实 PPTX；P0 清单把每个相关菜单方法映射具体测试子用例。

动作在菜单执行清单中的文档操作
界面pending、成功后刷新画布

2
动作agent 读取并再修改，用户撤销/重做
界面所有观察端显示同一版本
系统使用统一历史与状态协议
结果没有 UI/tool 分叉
3
动作网页放映或导出图片/PDF，再保存重开
界面展示放映状态/输出文件
系统浏览器展示或服务导出并持久化
结果输出内容可打开验证
对象/参数无效
不存在元素、非法索引或尺寸
清楚报校验错误
恢复: 重新读取选择有效对象
媒体/放映权限失败
媒体不可解码、浏览器拒绝弹窗/全屏
显示原因和重试入口，保留内容
恢复: 更换媒体或用户手势重试

UF-005 服务型功能在网页可用

前置: 分已配置与未配置服务两组，服务包含打印、OCR、模型、搜索、生图、媒体分析；禁用未经配置的外发。

前置依赖缺失
未配置 provider/打印程序缺失

恢复: 配置完成后重新探测
运行时失败
超时、认证过期、空输出或用户取消
显示具体原因、内容保留
恢复: 恢复依赖后显式重试
